# Itens para materializar

Uma lista pessoal de itens para montar o setup, feita com HTML, CSS e JavaScript puro.

## Funcionalidades

- Adicionar item e valor
- Salvar tudo no `localStorage`
- Marcar como "Adquirido"
- Registrar automaticamente a data de aquisição
- Separar itens pendentes e adquiridos
- Animação ao adquirir um item
- Contador e progresso da lista
- Total dos valores
- Excluir itens
- Limpar a lista inteira
- Layout responsivo para celular
- Ícones via Lucide

## Como executar

Não precisa instalar nada.

1. Extraia o projeto.
2. Abra `index.html` no navegador.
3. Comece a adicionar seus itens.

Os dados ficam salvos no navegador usando `localStorage`. Se o armazenamento do navegador for apagado, a lista também será apagada.
